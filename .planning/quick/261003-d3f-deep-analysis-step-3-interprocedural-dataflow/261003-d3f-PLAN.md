## Tasks

1. **Program representation.** The tree-sitter Go MIR cannot carry interprocedural taint (it drops literal arguments,
   receivers, `var` initializers, all but the last value of a multi-assignment, range and type-switch variables, and
   merges shadowed locals and captures). The semantic sidecar emits a per-function flow program from SSA instead
   (`--dataflow`), statically dead branches pruned first; polint lowers it while decoding.
2. **Solver.** Access-path facts (k = 2, 3 on request), per-(function, entry) summaries reused across callers with
   equality backdating in recursive cycles, returns to callers, package variables, closures, library functions by
   model or by a conservative default, per-package step budgets and a deadline reported as unknowns, path recovery,
   precision labels.
3. **Models as data.** Built-in sources (gin/net-http request data, Watermill payloads), sinks (GORM and
   `database/sql` query text, commands, logging, publishing), sanitizers, opaque functions and propagators, plus a
   repository's `[[go_flow_*]]` tables.
4. **SDK.** `DataFlow<'_>::flows(&FlowSpec)` → `FlowAnswer` with flows (source, sink, steps, precision, unknowns) and
   run-wide unknowns; `Flow::diagnostic` with located path evidence (SARIF code flows); `DataFlow::forbidden` answered
   by the solver for Go. Docs, promotion record, outside-user CLI test.
5. **Taint corpus** of at least 40 cases from the consumers' error-flow, transaction, context and tenant-scope rule
   families, each with must-not-report twins, scored by the eval harness.
6. **Gate 3:** corpus precision ≥ 90 % / recall ≥ 70 %; L4 probes ≥ 9/10 Go positives with all twins clean;
   whole-core `dataflow` cold ≤ 120 s / ≤ 6 GB, warm ≤ 25 s, edit ≤ 20 s (reported, not binding after the gate-2
   kill); budget trips visible as unknowns. Kill: corpus precision < 80 % after two iterations → review-only.
7. Full gate suite on the final commit; mutation checks on summary equality backdating, budget unknowns, value
   kinds and the may-edge confidence; logical conventional commits; push `perf/deep-analysis`.
