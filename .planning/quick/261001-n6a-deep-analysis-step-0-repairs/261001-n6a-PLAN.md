## Tasks

1. **Symbols sidecar loads modules newer than the host Go.** Write the synthetic `go.work` with the
   highest `go` directive of the module roots (as the semantic sidecar already does), in a private
   temporary directory removed with its `go.work.sum`. Run the embedded sidecar the way the semantic
   one runs: build it once with the local toolchain into the private binary cache, then execute it
   without a `GOTOOLCHAIN=local` pin, so its own `go list` honours the module's `go` line exactly as
   `go build` in that module would.
2. **Symbols sidecar failures are visible and never cached.** A failed load logs at warn level with
   the sidecar's reason and becomes one workspace diagnostic when a deep capability depends on it;
   a symbol graph that carries any setup-missing support is not written to the layer cache.
3. **Semantic sidecar load mode.** Dependencies from export data (no `NeedDeps`), SSA with
   `ssautil.Packages` for the roots only (the whole-program load stays only behind the test-only
   RTA-oracle switch, which release builds cannot set). `GOMEMLIMIT` defaults to a quarter of the
   memory available to polint unless the environment sets it. Test variants are opt-in for the
   semantic sidecar: an unset `[languages.go] include_tests` means "no tests" there and keeps
   meaning "tests" for the symbols sidecar; the effective value is in the semantic cache key. The
   sidecar reports its peak RSS, which the stage log prints next to its heap figure.
4. **`polint unknowns` fails loudly.** A provider in the requested capability's closure that failed,
   was blocked, hit a budget or is setup-missing — and any non-supported capability support the
   capability depends on — becomes an error row naming the provider and the reason, and the
   command exits 1. An empty list means "nothing unknown", never "nothing ran".
5. **Compact abstract domains by default.** The provider materializes summary inputs unless the
   plan asks for per-point domain states, which only an internal request can do today.
6. **Layer read limit and grammar.** Raise the layer payload read limit from 64 MiB to 256 MiB;
   take PR #126 (vendored tree-sitter-go with the `new(expr)` widening).
7. **Tests.** Each change carries tests; mutation-verify the compact-domains default and the
   setup-missing no-cache rule. Full gate suite on the final commit: fmt, clippy `-D warnings`,
   rustdoc `-D warnings`, the lib suite, every integration target, doctests, the other crates and
   the language-feature matrix.
8. **Gate 0** (recorded in `/opt/data/polint-deep/gates.md`): catalog `control_flow` cold ≤ 15 s
   and ≤ 2.5 GB tree peak; catalog `calls` warm ≤ 8 s and ≤ 1 GB; `--cap references` returns 0

   every rule requesting no deep capability (OAIZ full-repository `check`, BASE host vs FINAL host,
   every difference attributed). Interleaved BASE/FINAL samples, medians, tree RSS through the
   research round's sampler with a kill ceiling.
