  <action>
    `corrections.rs`: `Correction { graph: PackageGraphIdentity, anchor: Anchor (Function | CallSite, with body hash), op: Op (AddEdge { target }, RejectEdge { target }, MarkComplete, AddBoundaryFact), evidence: CorrectionEvidence (Observed { run, driver } | Test { path, command } | Review { who, read }), stage, engine_version }`. A loader from the recorder format: map each observed edge to a site and a callee by the bench's rule, anchored by the identities with the body hash at load time. `apply(graph, corrections) -> (graph', report)`: add edges with evidence `observed`, tier conservative (an observation proves an edge, not completeness; rule 4), never remove; a correction whose anchor's body hash differs is `stale` in the report and skipped; a correction the engine already derives is `derived` in the report (the retire-as-fixture signal). The engine's analysis never calls this module (a test greps the kernel's provider graph for the module name and finds it only in the post-engine step).
